## The problem

Verus Virtus is a small firm in Kuala Lumpur building AI, blockchain and big-data
systems for government and enterprise clients. Almost none of that work can be shown
publicly, which is the constraint the whole site is built around: it has to convince
a serious buyer of capability while saying very little about specific projects. The
positioning line, "deep tech, built with discretion", is the site admitting that
tension rather than working around it.

## How it works

One page, anchored sections — About, Capabilities, Approach, Work, Contact — so the
whole pitch can be read in a single scroll and any part of it linked to directly.
Built with Next.js on the App Router and deployed to Vercel, styled with Tailwind,
set in Geist and Geist Mono. There is no animation library: the motion that is there
comes from CSS, which keeps the page fast and the dependency list short.

I designed and built it as the company's first software engineer, working from the
positioning outwards rather than from a template inwards.
